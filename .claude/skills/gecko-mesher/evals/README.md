# Test cases for gecko-mesher

Each folder is one case in the layout `claude plugin eval` reads; the
skill-creator workflow runs them too.

`B1.step` and `B1.msh` are model B1 of the MAMBO dataset
(https://github.com/franck-ledoux/mambo), licensed CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/). `B1.msh` is the STEP file
turned into a gmsh surface mesh; it is otherwise unchanged.
